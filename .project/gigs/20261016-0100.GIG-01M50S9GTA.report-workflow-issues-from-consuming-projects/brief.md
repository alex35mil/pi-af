# Brief

Let agents using these workflows in any repository report reproducible workflow defects or friction back to a dedicated maintainer agent for `pi-af`.

Before implementation, define:

- Reporting destination and transport.
- User-approval boundary.
- Protection of private or sensitive consuming-project data.
- Workflow version and source identification.
- Reproducible context required for investigation.
- Maintainer intake and triage flow.

Do not assume that the consuming project's tracker is the workflow-maintenance tracker.
