# Brief

Configure GitHub forge tools required by workflow merge checks

GitHub workflow setup enables `pull_requests` for the forge role, or `issues,projects,pull_requests` with tracking. The merge procedure also requires verification of repository protections and access.

2. Submit a PR and request shipping.
3. Reach repository-protection verification without the required inspection tools.

**Expected**
Workflow setup supplies and validates the supported MCP capabilities required by its merge procedure, with upgrade guidance for existing configurations. Verify the actual tools needed; adding `repos` alone has not been confirmed sufficient.
