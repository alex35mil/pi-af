# Brief

Add repository descriptions and default to Backlog in GitHub Project setup

Update GitHub Project setup to:

1. Set the Project description to `Repository: https://github.com/<owner>/<repo>`, using the repository being configured.
2. Set GitHub’s native Project default status to **Backlog**. It currently defaults to **Todo**, as reported during setup.

The description provides a repository reference from the Project. Its URL clickability has not been verified.

Affected workflow: `/project-setup` and GitHub Project provisioning. Installed workflow revision was not established.
